# The Appointment React Rebrand

## Run locally

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite.

## Structure
Each website section is a separate component with its own JSX and CSS file under `src/components`. Brand images are in `src/assets/images`.

## Brand system used
- Teal Green: `#1A9A8B`
- Deep Orange: `#BF5B1B`
- White: `#FFFFFF`
- Headings: Lora
- Body: Montserrat

Update registration / Telegram destinations in the relevant component anchor links when the final URLs are available.
